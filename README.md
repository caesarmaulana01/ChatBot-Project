# PST Chatbot

PST Chatbot is a Telegram bot developed during an internship at Badan Pusat Statistik Aceh, aimed at enhancing the Q&A services of the agency. The bot processes raw chat data through a series of cleaning steps, including case folding, removal of non-ASCII characters, and flagging questions and answers. Built with Python and Telegram's Bot API, it utilizes TF-IDF and cosine similarity for responding to user queries based on a cleaned dataset.

## Features
- **Data Cleaning**: Transforms raw chat data into a structured format.
- **User-Friendly Interface**: Offers inline keyboard options for seamless interaction.
- **24/7 Availability**: Hosted on PythonAnywhere for constant access.

## Usage
- Interact with the bot to ask questions regarding statistics data.
- Use the provided buttons for quick navigation and assistance.
